# Gal World 0.0.3

[English](0.0.3.en.md) | 简体中文

本版聚焦首屏与页面跳转时的加载体验。Vue 挂载前先渲染启动骨架，各页面骨架与真实布局对齐，首屏接口由串行改为并行。

页面跳转补齐五层反馈：点击缩放、悬停预取、延迟进度条、新页淡入、骨架按视觉行错峰入场。从游戏详情返回列表时，首屏数据渲染完成后再恢复原来的滚动位置。

默认主题改为浅色「素纸」；自定义主题可在卡片上单独删除，正在使用的主题需先切换才能删除。版本号统一只从 `portal/pom.xml` 读取。

## 重点功能

- **首屏骨架**：`index.html` 内置挂载前骨架；首页、列表、详情、设置与管理表格共用骨架块；卡片图标延迟加载
- **请求并行**：设置只请求一次并全局共享；首页 Hero 与推荐同时发出；列表元数据与首页列表同时发出；详情页的存档、时长、设置、下载查询一起发出
- **跳转反馈**：悬停预取路由 chunk、80 ms 延迟进度条、180 ms 新页淡入、骨架按视觉行错峰、浏览器前进/后退补 `scrollBehavior`
- **滚动恢复**：返回游戏列表时，第一页数据进 DOM 后再对齐到离开时的位置
- **主题**：默认主题改为「素纸」；自定义主题卡片右上角可删除；正在使用的主题拒绝删除；浏览器 `theme-color` 跟随当前主题
- **版本管理**：产品版本只来自 `portal/pom.xml`；`package.json`、README 与发布脚本不再重复维护

## 修复

- 预取逻辑拆到独立模块，打断 router ↔ 视图的循环依赖
- 进度条状态改为普通对象并由组件注入响应式代理，修复进度条不更新的问题
- 滚动恢复不再读取 vue-router 内部 `history.state`，位置由 `scrollBehavior` 的 `savedPosition` 记录
- 进度条淡出期间开始新导航时，不再出现宽度回跳
- 自定义主题删除与默认主题切换的边界行为修正

## 升级说明

无需迁移数据库或执行额外步骤。已保存主题的本机不受默认主题变更影响；只有从未选过主题的浏览器会看到「素纸」。正在使用的自定义主题需先切换到其它主题才能删除。

## 已知限制

- Linux 无 GPU 时使用软渲染与软编码，性能取决于主机 CPU。
- 浏览器串流要求反向代理支持 WebRTC / WebSocket upgrade。
- H2 是文件数据库，不要让多个 Portal 实例指向同一个数据目录。
