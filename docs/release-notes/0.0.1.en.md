First release. A self-hosted cloud gaming platform for Windows visual novels (galgames):
deploy games to a Linux or Windows host and play them in the browser. The portal owns the
game library, metadata, sessions, media, saves and operations; streaming is handled by
Selkies (Linux) or Sunshine + Moonlight Web (Windows).

## Features

- **Browser play** — Selkies + Wine on Linux, Sunshine + Moonlight Web on Windows
- **Isolated games** — per-game wine prefix, virtual display, ALSA slot, audio chain and
  port; one broken game does not affect the others
- **Sessions survive disconnects** — closing the browser does not stop the game; reconnect
  from another device and continue
- **Library** — filters by company / localization group / tag, search, quick start-stop,
  cover and CG rotation
- **Import wizard** — upload a zip / 7z or a whole folder (chunked, resumable), or pick a
  directory already on the server
- **Metadata and media** — companies, localization groups, tags, covers, icons, image
  preloading
- **Saves** — tagged backups, one-click switching, download; the current progress is
  snapshotted before switching; the original save cannot be deleted
- **Operations** — one-click deploy / uninstall with live logs, remote update with
  rollback, game package download

## Fixed in this release

- Closing a game now asks the game to exit first and waits for it to flush saves before
  stopping the stream, so progress is no longer lost
- Session logs are rotated, so long sessions no longer grow without bound
- Switching saves keeps a snapshot of the current progress, so switching away and back no
  longer discards saves made in between

## Notes

- Without a GPU on Linux the pipeline falls back to software rendering and software
  encoding; benchmark results do not carry over to machines with a GPU
- Browser streaming relies on WebRTC / WebSocket; a reverse proxy in between must support
  upgrade
- H2 is a file database; never point two portal instances at the same data directory
- 0.0.1 is re-released: game shutdown and save switching were broken in the earlier build

## Requirements

Linux: Ubuntu 22.04+ / 24.04, Wine 9.0, PulseAudio, snd-aloop, Xvfb, Selkies
Windows: 10 1903+ / 11 (x64), Sunshine, Moonlight Web, virtual audio cable
