# Gal World 0.0.3

English | [简体中文](0.0.3.zh.md)

This release focuses on first-screen and navigation loading. A boot skeleton now renders before Vue mounts, page-level skeletons match the real layout, and first-screen requests run in parallel instead of serial chains.

Route changes get a five-layer feedback chain: click feedback, hover prefetch, a delayed progress bar, page fade-in, and row-staggered skeleton entrance. Returning from a game detail page restores the list scroll position after data arrives.

The default theme is now the light "paper" theme. Custom themes can be deleted from their card, while the theme currently in use cannot be deleted until another one is selected. Version numbers now live only in `portal/pom.xml`.

## Highlights

- **First screen:** pre-mount skeleton in `index.html`; skeleton blocks shared by homepage, list, detail, settings and management tables; card icons load lazily
- **Faster data:** settings are fetched once and shared; homepage hero and recommendations run in parallel; list metadata and first page run in parallel; detail page starts saves, playtime, settings and download queries together
- **Navigation feedback:** hover prefetch of route chunks, 80 ms delayed progress bar, 180 ms page fade-in, skeleton blocks animated by visual row, and `scrollBehavior` for back/forward
- **Scroll restoration:** returning to the game list re-aligns to the previous position after the first page of data is rendered
- **Theme:** default theme changed to "paper"; per-card deletion for custom themes with a guard for the active theme; browser `theme-color` follows the active theme
- **Release hygiene:** version is read from `portal/pom.xml` only; no duplicate version in `package.json`, README or release scripts

## Fixes

- Decoupled route prefetch from the router module, removing a router ↔ view circular import
- Made progress-bar state observable again after moving to a Vue-free, testable module
- Scroll restoration no longer reads vue-router internal `history.state`; saved positions come from `scrollBehavior`
- Progress bar no longer jumps backwards when a new navigation starts during the fade-out window

## Upgrade notes

No database migration or manual action is required. Existing users keep their locally stored theme; only browsers without a saved theme see the new default. A custom theme in use must be switched before it can be deleted.

## Known limits

- Linux without a GPU uses software rendering and encoding; performance depends on host CPU.
- Browser streaming requires WebRTC/WebSocket upgrade support from reverse proxies.
- H2 is a file database; do not point multiple Portal instances at the same data directory.
