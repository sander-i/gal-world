# Gal World 0.0.2

[English](0.0.2.en.md) | 简体中文

本版加入 English / 简体中文 / 繁體中文 / 日本語界面，支持导入并安装外部语言包；公司、标签、汉化组的名称与简介可按语言配置。

同时加入可配置的更新源、更安全的存档切换与备份描述、原始存档留底、游戏异步打包下载，以及前后端性能优化。

## 重点功能

- **多语言**：导入 `.po`、XLIFF、CSV、properties、Android XML、`.arb`、`.strings`；也可从公网 HTTP(S) 直链安装语言包
- **多语言元数据**：公司、标签、汉化组名称与简介独立按语言设置
- **存档**：切换备份前自动快照当前进度；支持标签和描述；自动保留游戏原始存档
- **游戏下载**：异步打包并显示进度；排除门户生成的 `game.env` 与 `wineprefix/`
- **性能**：路由懒加载、Element Plus 样式按需摇树、gzip、HTTP/2、ETag 缓存、批量查询与会话轮询
- **会话体验**：全部游戏卡片显示启停进度；游戏运行时首页每秒刷新状态

## 实测结果

Windows 开发机 + H2 + 40 款构造游戏：`GET /api/games?limit=40` 从 1004 条 SQL 降到 13 条；推荐接口从 579 条降到 12 条。Linux 生产实机验证了批量会话状态对 RUNNING / STOPPED 的映射。

测量方法、环境边界与取舍见 `docs/PERF-PLAN.md` 第 8 节。以上不是生产规模的性能基准。

## 升级说明

无需手动迁移数据库或执行额外步骤。若当前选择的语言包不可用，界面会回退到 English。

## 已知限制

- Linux 无 GPU 时使用软渲染与软编码，性能取决于主机 CPU。
- 浏览器串流要求反向代理支持 WebRTC / WebSocket upgrade。
- H2 是文件数据库，不要让多个 Portal 实例指向同一个数据目录。
