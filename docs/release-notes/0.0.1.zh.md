首个发布版本。自建云游戏平台：把 Windows 视觉小说（galgame）部署到 Linux 或
Windows 主机，通过浏览器直接游玩。门户负责游戏库、元数据、会话、媒体、存档与运维，
画面和声音由串流端承担。

## 功能

- **浏览器游玩**：Linux 走 Selkies + Wine，Windows 走 Sunshine + Moonlight Web
- **资源隔离**：每个游戏独立 wine prefix、虚拟显示号、ALSA 槽位、音频链与端口，
  一个游戏出问题不影响其它游戏
- **断线不掉线**：关闭浏览器不会结束会话，换设备连回去进度还在
- **游戏库**：公司 / 汉化组 / 标签筛选、搜索、卡片快捷启停、封面与 CG 轮换
- **接入向导**：上传 zip / 7z 或整个文件夹（分片、可续传），也可直接选服务器目录
- **元数据与媒体**：公司、汉化组、标签、封面、图标、图片预加载
- **存档**：带标签备份、一键切换、下载；切换前自动保留当前进度；原始存档不可删除
- **运维**：一键部署 / 卸载（实时日志）、远程更新带回滚、游戏打包下载

## 本版重点修复

- 关闭游戏时先请求游戏自身退出，等它把存档写盘后再收流，不再丢进度
- 会话日志加轮转，长会话不再无限增长
- 存档切换保留当前进度快照，切走再切回不会丢失期间新增的存档

## 说明

- Linux 端无 GPU 时走软渲染 + 软编码，性能以实测为准，结论不能套到有显卡的机器
- 浏览器串流依赖 WebRTC / WebSocket，中间有反向代理时需支持 upgrade
- H2 是文件库，不要让两个门户实例指向同一个数据目录
- 重新发布 0.0.1：关闭游戏与存档切换的基础功能此前有问题，请使用本版

## 环境要求

Linux：Ubuntu 22.04+ / 24.04，Wine 9.0、PulseAudio、snd-aloop、Xvfb、Selkies
Windows：10 1903+ / 11（x64），Sunshine、Moonlight Web、虚拟声卡
