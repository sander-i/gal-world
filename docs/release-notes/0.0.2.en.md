# Gal World 0.0.2

English | [简体中文](0.0.2.zh.md)

This release adds built-in English, Simplified Chinese, Traditional Chinese and Japanese UI, with external language-pack import and installation. Company, tag and localization-group names and descriptions can be localized independently.

It also includes configurable update sources, safer save switching and backup descriptions, original-save snapshots, asynchronous game-package downloads, and substantial frontend/backend performance improvements.

## Highlights

- **Localization:** Import `.po`, XLIFF, CSV, properties, Android XML, `.arb` and `.strings` packs; install packs from direct public HTTP(S) links
- **Metadata:** Localized names and descriptions for companies, tags and localization groups
- **Saves:** Switch backups with an automatic pre-switch snapshot; add labels and descriptions; preserve original game saves
- **Downloads:** Build game archives asynchronously with progress; generated `game.env` and `wineprefix/` are excluded
- **Performance:** Lazy-loaded routes, tree-shaken Element Plus styles, gzip, HTTP/2, ETag caching, batched queries and session polling
- **Session UX:** Start/stop progress on all-game cards; homepage status refreshes once per second while a game runs

## Measured results

On a Windows development machine with H2 and 40 synthetic games, `GET /api/games?limit=40` fell from 1004 SQL statements to 13; recommendations fell from 579 to 12. Production Linux testing verified batched session status mapping for running and stopped games.

See `docs/PERF-PLAN.md` section 8 for methodology, environment limits and trade-offs. These figures are not a production-scale benchmark.

## Upgrade notes

No database migration or manual action is required. Existing language settings fall back to English if the selected pack is unavailable.

## Known limits

- Linux without a GPU uses software rendering and encoding; performance depends on host CPU.
- Browser streaming requires WebRTC/WebSocket upgrade support from reverse proxies.
- H2 is a file database; do not point multiple Portal instances at the same data directory.
