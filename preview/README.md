# preview —— 静态界面原型

双击任意 HTML 即可打开（纯静态、无需构建、无需后端）。

原型只用于对齐交互与视觉，真实实现见 [`portal/frontend`](../portal/frontend/)；两者不一致时以真实前端为准。

## 页面

| 文件 | 对应页面 |
|---|---|
| `index.html` | 首页（游戏库）：Hero 推荐位、公司/标签筛选、游戏卡片 |
| `game.html` | 游戏页（详情）：左信息与操作、右大屏展示（封面 / CG 切换）、简介、存档备份 |
| `edit.html` | 游戏编辑页：字段、封面 / 图标 / 宣传 CG、轮换规则、服务器路径 |
| `settings.html` | 全局设置：切换方式、空闲停止、CG 声音、上传限制、轮换功能、图片预加载、游戏页展示 |

顶部原型导航可在四个页面之间跳转。

## 封面 / CG 预览

- **预览按钮**：编辑页每行右侧的「预览」按钮，或直接点缩略图，打开灯箱；支持 ← / → 切换、Esc 关闭，关闭时视频暂停并释放。
- **悬停小窗**：仅在编辑页生效。鼠标停在封面 / CG 缩略图上约 0.15 秒，弹出 320×180 小窗显示图片或播放视频；移开即关闭。
- 游戏页大屏不提供悬停小窗，按实际页面自动轮换。

## 编辑页上传演示

点「模拟一批文件」可走完整流程：

- 预检对话框：按剩余名额、格式、单文件大小汇总「可上传 / 被拒绝」，确认后才开始上传；
- 并发 2 路上传，单文件进度条与状态徽标（等待 / 上传中 / 已上传 / 失败）；
- CG 批次里的 `cg-net-fail.png` 固定在 62% 失败，点「重试」成功；
- 上传中点「取消」立即移除；
- 把本地文件拖到「封面列表 / CG 列表」区块任意位置即可加入队列；
- 拖动行首 ⠿ 调整顺序；删除已保存项会标「待保存删除」并可撤销；删除与排序都要点「保存」才生效（与方案一致）。

## 说明

- 上传、保存、删除、设置切换都是浏览器内的模拟，不会发出请求，也不会改动服务器文件。
- 示例图片由 canvas 现场生成；示例视频由 `MediaRecorder` 现场录制（浏览器不支持时退回静帧）。
- 配色、字号、控件高度直接复用 `portal/frontend/src/styles.css`（`preview/styles.css` 为其副本），与门户一致；`preview.css` 只包含原型专用的悬停小窗、灯箱、上传队列等样式。
